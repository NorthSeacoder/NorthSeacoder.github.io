## useage
```js
hexo new [layout] [title] --cata=xxx
=>_post/layout/cata/title.md

```
## layout 及 cata 取值
- algo(算法)
    - 91(91 天学算法)
    - base(基本数据结构)
    - tpl 常见算法套路
- idn(我不知道的 xx)
    - js
    - vue
- base(基础)
    - network
    - algo:模板
    - frame:各种框架
    - js
    - css
    - html
    - tools:工具类
    - 手写
    - ts
