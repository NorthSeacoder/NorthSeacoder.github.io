## src 和 href 的区别(1)

-   都是用来引用外部资源
-   src
    -   表示对资源的引用,指向的内容会嵌入到当前标签所在的位置
    -   src 会将其指向的资源下载并应用到文档内:例如请求 js 脚本
    -   解析到该元素时,会暂停其他资源的下载和处理
-   href:
    -   表示超文本引用,指向一些网络资源,建立和当前元素的链接关系
    -   当浏览器识别到它指向的文件是,才会下载资源,不会停止对当前文档的处理

## 对 HTML 语义化的理解(1)
-   语义化指根据内容的结构选择合适的标签,通俗来讲就是用正确的标签做正确的事
-   优势:
    -   对机器友好,适合爬虫获取有效信息,有利于 SEO,配合读屏软件,根据文章自动生成目录
    -   对开发者友好,语义类标签增强可读性,结构更加清晰,便于团队开发维护
-   常见语义化标签:header(头部),nav(导航栏),section(区块),footer(页脚),main(主要区域),article(主要内容),aside(侧边栏)

## DOCTYPE(⽂档类型) 的作⽤(2)

-   DOCTYPE 是 HTML 文档的开始标签,它指定了文档的类型,以及编码方式
-   告诉浏览器以什么样的方式解析文档(html/xhtml)

## script 标签中 defer 和 async 的区别(1)

-   都是异步加载外部脚本,不会阻塞页面解析
-   区别:
-   执行顺序:async 不能保证加载顺序,defer 按照加载顺序执行
-   脚本是否立即执行:async 可以立即执行,defer 必须等到页面加载完成才能执行

## 常用的 meta 标签有哪些(2)

-   meta 标签由 name 和 content 属性定义,用来描述网页文档的属性
-   常见 meta:
    -   charset:描述文档的编码类型
    -   keywords:页面关键词
    -   description:页面描述

## HTML5 有哪些更新(1)

-   语义化标签
-   媒体标签:audio,video
-   表单
-   进度条,度量器
-   DOM 查询:document.querySelector
-   web 存储:localStorage

## img 的 srcset 属性(3)

-   响应式页面中根据屏幕密度设置不同图片

## 行内元素有哪些,块级元素有哪些,空元素有哪些(1)

-   行内元素:a,b,span,img,input,select,strong
-   块级元素:div,ul,ol,li,h1,h2...,p
-   空元素(无闭合标签):br,hr,colgroup

## web worker(2)

-   运行在后台的 js,独立于其他脚本,不会影响页面性能,通过 postMessage 将结果回传给主线程

## title 与 h1 的区别/b 与 strong 答得区别/i 与 em 的区别(2)

-   h1 表示层次明确的标题
-   strong 表示加强语气
-   i 为斜体,em 表示强调的文本

## iframe 的优点和缺点(4)

-   优点:
    -   加载速度较慢的内容(广告)
    -   使脚本并行下载
-   缺点:
    -   阻塞主页面 onload 事件
    -   无法被搜索引擎识别
    -   产生很多页面不容易管理

## label 的作用?如何使用(3)

-   定义表单控件的关系:当用户选择 label 标签时，浏览器会自动将焦点转到和 label 标签相关的表单控件上。
-   使用方式:包住表单控件,或与表单控件直接相邻

## head 标签有什么作用,哪些必须(2)

-   定义文档头部,是所有头部元素的容器,title 是唯一必须的元素
