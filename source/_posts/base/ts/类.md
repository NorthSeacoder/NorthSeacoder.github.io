## 构造函数

-   类的构造函数可以重载,但是没有返回值的类型注释(永远返回的是类实例)

```ts
class Point {
    // Overloads
    constructor(x: number, y: string);
    constructor(s: string);
    constructor(xs: any, y?: any) {
        // TBD
    }
}
```

## 类的继承

-   构造函数中在使用 this 之前调用 super();
-   子类可修改 protected 属性为 public

## 类的属性和方法

## 修饰符

### 修饰属性与方法

-   public:默认
-   protected:本身及子类可访问,实例不能
-   private:仅限类本身访问

### 修饰构造函数参数

-   结果等同配置相应修饰符的属性并赋值

### 修饰构造函数

-   private:既不能实例化也不能被继承
-   protected:不能实例化，只能被继承，相当于生成了一个基类

## 静态属性

-   只能用类名能调用的属性

```ts
class MyClass {
    static x = 0;
    static printX() {
        console.log(MyClass.x);
    }
}
console.log(MyClass.x);
```

-   静态属性可以设置修饰符
-   也可以被继承

## 抽象类
- 只能被继承,不能实例化
- 继承时,抽象类的方法不强制实现
- 抽象方法:不包含具体实现并且必须在派生类中实现,与接口类似,抽象方法必须包含abstract关键字并且可以包含访问修饰符

## 类与接口的关系
- 实现接口需要实现所有方法
- 接口只能约束公有成员
- 接口可以继承多个类
- 接口可以继承类,会抽象类中的所有属性(public，protected，private)
