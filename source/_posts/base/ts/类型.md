## 函数定义方式

```ts
function fn(firstName: string = 'name', lastName?: string): void;

const fn2: (x: number) => number;

type fn3 = (x: number) => number;

interface fn4 {
    (x: number): number;
}
```

### 函数重载

-   函数名字相同，而参数不同，返回类型可以相同也可以不同
-   每个重载的方法（或者构造函数）都必须有一个独一无二的参数类型列表。

```ts
//类型不同
function disp(string): void;
function disp(number): void;
//数量不同
function disp(n1: number): void;
function disp(x: number, y: number): void;
//类型顺序不同
function disp(n1: number, s1: string): void;
function disp(s: string, n: number): void;
//此时不用再次定义类型
function disp(s) {}
```

## 枚举类型

-   枚举可扩充:代码运行的当前作用域中已经存在了枚举变量，那么就会直接在当前变量上面扩展

```ts
enum Color {
    Red,
    Green,
    Blue
}

enum Color {
    DarkRed = 3,
    DarkGreen,
    DarkBlue
}
```

-   数字枚举类型实现方式:反向映射

```ts
enum G {
    a,
    b,
    c
}
//=>
var G;
(function (G) {
    G[(G['a'] = 0)] = 'a';
    G[(G['b'] = 1)] = 'b';
    G[(G['c'] = 2)] = 'c';
})(G || (G = {}));
G = {
    '0': 'a',
    '1': 'b',
    '2': 'c',
    a: 0,
    b: 1,
    c: 2
};
```

-   字符串枚举没有反向映射
-   非常量枚举成员会在运行时进行计算

```ts
enum G {
    a = Math.random(), //非常量枚举成员:运行时计算结果
    b = 1 + 3 //常量枚举成员:编译时出结果
}
```

-   常量枚举(编译阶段会被移除)
-   不需要一个对象,只需要对象的值
-   减少编译环境的代码

```ts
const enum Color {
    Red,
    Green,
    Blue
}

let c: Color = Color.Green;
//=>
var c = 1; /* Green */
```
